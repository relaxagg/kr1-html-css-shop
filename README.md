# TechPoint — магазин смартфонов и гаджетов

Учебный многостраничный HTML/CSS-сайт интернет-магазина техники TechPoint.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Дисциплина: «Фронтенд и бэкенд разработка».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина: главная страница, каталог с фильтрами, страница товара с таблицей характеристик, страница оформления заявки и страница контактов.

## Ссылка на опубликованный проект

GitHub Pages: https://relaxagg.github.io/kr1-html-css-shop/

## Как посмотреть проект

1. Открыть ссылку GitHub Pages выше.
2. Или скачать репозиторий и открыть файл `index.html` в браузере.

## Структура проекта

- `index.html` — главная: hero-блок, преимущества, популярные товары, FAQ, модальное окно заявки;
- `catalog.html` — каталог: фильтры и сетка из 6 товаров;
- `product.html` — карточка товара: изображение, цена, таблица характеристик, кнопка заявки;
- `order.html` — страница оформления заявки с формой;
- `contacts.html` — контакты и блок обратной связи;
- `css/style.css` — общий файл стилей;
- `js/main.js` — модальное окно и обработка форм;
- `images/` — SVG-изображения товаров;
- `sitemap.xml` — карта сайта;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Что реализовано по требованиям КР №1

| Требование | Где реализовано |
| --- | --- |
| Семантика | `header`, `nav`, `main`, `section`, `article`, `aside`, `footer` на всех страницах |
| Навигация | единое меню на всех страницах, якоря `#advantages`, `#popular`, `#contacts`, хлебные крошки |
| Карточки | `product-card` на главной и в каталоге |
| Таблица | характеристики товара на `product.html` (`caption`, `thead`, `tbody`, `th`, `td`) |
| Форма | модальное окно на главной и отдельная форма на `order.html` |
| Модальное окно | `<dialog class="order-dialog">` на главной |
| CSS | переменные в `:root`, состояния `:hover`, `:focus-visible`, `:disabled` |
| Flex/Grid | меню и карточки — Flexbox; сетка товаров, каталог, страница товара, заявка — Grid |
| БЭМ | все компоненты названы по БЭМ (список ниже) |
| Позиционирование | `relative` + `absolute` (бейджи), `sticky` (шапка и фильтры), `fixed` (кнопка «Наверх», сообщение об отправке), `z-index` |

## Позиционирование

- `.product-card` — `position: relative`, контейнер для бейджа;
- `.product-card__badge` — `position: absolute`, бейджи «Скидка», «Хит», «Новинка»;
- `.site-header` — `position: sticky`, шапка остаётся вверху при прокрутке, `z-index: 10`;
- `.catalog-filters` — `position: sticky`, фильтры каталога не уезжают при прокрутке;
- `.to-top` — `position: fixed`, кнопка «Наверх», `z-index: 20`;
- `.success-message` — `position: fixed`, всплывающее сообщение об отправке заявки, `z-index: 30`.

## Самостоятельные доработки

- **Собственная тематика и оформление.** Сайт оформлен как магазин техники TechPoint: своя палитра в `:root`, тёмный hero-блок, логотип, тёмный подвал из трёх колонок.
- **Дополнительные страницы и блоки.** Страницы `product.html` и `order.html`, блок «Частые вопросы» на `<details>`, блок «Что мы проверили перед продажей», шаги оформления заказа.
- **Расширенный каталог.** 6 товаров в трёх категориях, у каждой карточки изображение, категория, описание, цена и старая цена для товаров со скидкой.
- **Варианты карточек через БЭМ-модификаторы.** `product-card--discount`, `product-card--featured`, отдельный блок `badge` с модификаторами `badge--sale`, `badge--hit`, `badge--new`.
- **Улучшенные фильтры.** Фильтры по категории, бренду и цене, кнопка сброса, sticky-позиционирование.
- **Пользовательский сценарий заявки.** В модальном окне показывается выбранный товар. Кнопка «Оформить заявку» на странице товара открывает `order.html` с уже выбранным товаром. После отправки появляется всплывающее сообщение, которое скрывается через 5 секунд.
- **Доступность.** Ссылка «Перейти к содержимому» для клавиатуры, `aria-current="page"` у активного пункта меню, видимый фокус у всех интерактивных элементов, `alt` у изображений, подсказка к телефону через `aria-describedby`, отключение плавной прокрутки при `prefers-reduced-motion`, контраст текста и кнопок не ниже 4.5:1.
- **Кнопка «Наверх»** и учёт высоты sticky-шапки при переходе по якорям (`scroll-margin-top`).

## БЭМ-структура проекта

- `site-header` — шапка сайта;
- `site-nav` — основная навигация (`site-nav__link--active`);
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `advantages-list` — преимущества магазина;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара (`--discount`, `--featured`);
- `badge` — бейдж (`--sale`, `--hit`, `--new`);
- `faq` — частые вопросы;
- `catalog-layout`, `catalog-filters`, `catalog-products`, `filters-form` — страница каталога;
- `product-page`, `product-table`, `check-list` — страница товара;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки (`--page` для отдельной страницы);
- `order-layout`, `order-steps` — страница заявки;
- `contacts-layout`, `contacts-card`, `contacts-list` — страница контактов;
- `button` — кнопка (`--primary`, `--secondary`, `--ghost`);
- `site-footer` — подвал сайта;
- `to-top`, `skip-link`, `success-message` — служебные элементы.
