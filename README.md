# TechPoint

Контрольная работа №1 по дисциплине «Фронтенд и бэкенд разработка».

Тема: «HTML и CSS: разработка многостраничного сайта».

Сайт магазина смартфонов TechPoint. В каталоге три модели: Samsung Galaxy S23, S23+ и S23 Ultra.

## Ссылка на сайт

GitHub Pages: https://relaxagg.github.io/kr1-html-css-shop/

Можно также скачать репозиторий и открыть `index.html` в браузере.

## Страницы

- `index.html` — главная: hero-блок, преимущества, популярные товары, модальное окно заявки
- `catalog.html` — каталог с фильтрами
- `product.html`, `product-s23.html`, `product-s23-plus.html` — страницы товаров (S23 Ultra, S23, S23+) с таблицей характеристик
- `order.html` — форма заказа
- `contacts.html` — контакты

Остальные файлы: `css/style.css` — стили, `js/main.js` — модальное окно, `js/catalog.js` — фильтры, `js/product.js` — выбор памяти и цвета, `images/` — фотографии товаров.

## Что использовано

- семантические теги: header, nav, main, section, article, aside, footer
- CSS-переменные, состояния :hover и :focus-visible
- Flexbox (шапка, меню, карточки) и Grid (сетка товаров, каталог, страница товара)
- БЭМ для классов (card, card__title, card--sale, nav__link--active и т.д.)
- позиционирование: шапка и фильтры — sticky, кнопка «наверх» и сообщение об отправке заявки — fixed, z-index у шапки и кнопки

## Доработки

- рабочие фильтры в каталоге: по модели и по цене, кнопка «Сбросить» и сообщение, если ничего не нашлось (`js/catalog.js`)
- отдельная страница для каждой модели, кнопки «Подробнее» в каталоге ведут на свою страницу
- на странице товара можно выбрать память (256 или 512 ГБ, 512 дороже на 4 000 ₽) и цвет (чёрный или белый), цена пересчитывается сама (`js/product.js`)
