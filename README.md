# TechPoint

Контрольная работа №1 по дисциплине «Фронтенд и бэкенд разработка».

Тема: «HTML и CSS: разработка многостраничного сайта».

Сайт магазина смартфонов TechPoint. В каталоге три модели: Samsung Galaxy S23, S23+ и S23 Ultra.

## Ссылка на сайт

GitHub Pages: https://relaxagg.github.io/kr1-html-css-shop/

Можно также скачать репозиторий и открыть `index.html` в браузере.

## Страницы

- `index.html` — главная: hero-блок, преимущества, популярные товары, модальное окно заявки
- `catalog.html` — каталог с фильтрами
- `product.html` — страница товара с таблицей характеристик
- `order.html` — форма заказа
- `contacts.html` — контакты

Остальные файлы: `css/style.css` — стили, `js/main.js` — модальное окно, `images/` — фотографии товаров.

## Что использовано

- семантические теги: header, nav, main, section, article, aside, footer
- CSS-переменные, состояния :hover и :focus-visible
- Flexbox (шапка, меню, карточки) и Grid (сетка товаров, каталог, страница товара)
- БЭМ для классов (card, card__title, card--sale, nav__link--active и т.д.)
- позиционирование: шапка и фильтры — sticky, бейдж на карточке — absolute внутри relative, кнопка «наверх» — fixed

## Технологии

HTML, CSS, немного JavaScript, Git, GitHub Pages.
